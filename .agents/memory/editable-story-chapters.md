name: Editable story chapters
description: How the startup / AI-learning / hackathon / event chapters and résumé link are meant to be maintained.
---

The user chose to fill in these chapters and the résumé link themselves later,
so they ship as bracketed drafts that only render in the dev preview.

**Why:** the user said "Keep the details editable for me. I'll provide/edit later"
and no approved facts exist; publishing invented details is not allowed.

**How to apply:** never flip a draft to published or replace placeholders with
guessed facts. When the user supplies details, edit the existing entries, then
verify evidence links / résumé downloads and mobile layouts before publishing.
