---
name: Published URL setting
description: Why the portfolio's production address is a blank, user-supplied setting and how SEO tags depend on it.
---

The portfolio's production address stays blank until the user supplies it; the user
will provide it later and asked to keep it editable.

**Why:** The project was unpublished when SEO work was done, and the user does not
want a guessed or preview domain used.

**How to apply:** When the user gives the URL, confirm it with deployment info,
set the single editable value in the site config, rebuild/republish, then verify
canonical tags, sitemap, redirects, 404 status, images and headers on the live host
and update the verification report.
